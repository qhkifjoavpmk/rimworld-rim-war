## Overview

Rim War transforms the passive faction map into a dynamic theater of war where AI factions raid each other, capture settlements, and shift borders based on military strength and political relations.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Rim War** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Faction Warfare** | AI factions autonomously attack and capture each other's bases |
| **Territory Map** | Overlay showing faction-controlled zones updated in real time |
| **Diplomacy Events** | Peace treaties, alliances, and betrayals trigger based on faction power |
| **Conquest Rewards** | Loot and goodwill bonuses for aiding allied factions in battle |
